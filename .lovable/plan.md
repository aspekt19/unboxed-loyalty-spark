
## План: Нативные приложения для App Store и Google Play

### Архитектура
Один кодбейс → две точки входа через URL-параметр/роутинг:
- **Loyal Spark** (`app.loyalspark.shopper`) — интерфейс покупателя
- **Loyal Spark Business** (`app.loyalspark.business`) — интерфейс мерчанта

### Шаги

1. **Установить Capacitor** — `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`

2. **Создать два режима приложения** — добавить `/app/shopper` и `/app/business` маршруты, которые сразу показывают нужный интерфейс без выбора роли

3. **Настроить Capacitor** — `capacitor.config.ts` с appId для Shopper-версии (основная). Для Business-версии — инструкция по переключению конфига

4. **Адаптировать навигацию** — убрать выбор роли в нативном режиме, сразу показывать нужный интерфейс

5. **Инструкция пользователю** — как собрать оба приложения через Xcode/Android Studio

### Что НЕ делаем сейчас
- Публикация в сторы (требует аккаунты разработчика)
- POS-интеграция (следующий этап)
- Push-уведомления (следующий этап)
