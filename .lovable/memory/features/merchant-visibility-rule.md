---
name: Merchant visibility rule
description: Discover "Listed" criteria (profile + paid plan + live program, no agents), merchant types; Your Merchants/direct links/agents unfiltered
type: feature
---
Human Discover shows only "Listed" merchants, enforced server-side:
- profile complete: business name, description, logo, location
- active PAID merchant plan (trial does not count; admin wallets count)
- at least one active, non-expired loyalty program
- not banned, not an AI agent (type "agent" or agent wallet)
Merchant types: In-store, Online, Program only, AI agent (agent never in human Discover; filter chips by type).
Unfiltered on purpose: "Your Merchants" (anyone who gave points), direct shop links, agent REST/MCP.
Owner dashboard (Business Profile) shows every remaining blocker.
Roadmap: "Near you" map, Verified badge, curated collections (Best cashback, New verified), admin moderation.
