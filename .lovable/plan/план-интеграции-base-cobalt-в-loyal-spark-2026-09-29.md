# План интеграции Base Cobalt в Loyal Spark

Cobalt активируется на Base mainnet 30 сентября 2026, 18:00 UTC. Работу начинаем после активации: сначала всё проверяем на Base Sepolia, потом включаем на mainnet.

## Этап 0 — Безопасное окно апгрейда (30 сентября)
- В приложении показываем баннер: с 17:30 до 19:00 UTC onchain-операции (деплой программ, выпуск токенов, P2P escrow) временно на паузе.
- Кнопки выпуска и деплоя в это окно отключены; агентские API возвращают понятную ошибку «повторите позже» (503 + Retry-After).
- Существующие B20 и legacy ERC-20 токены остаются без изменений, миграция не нужна.

## Этап 1 — Оплата газа в B20 (главная ценность)
Цель: клиенту и мерчанту не нужен ETH.
- Клиенты платят газ за перевод или погашение ваучера самими баллами программы (B20-токеном).
- Мерчант при создании программы включает «газ в токенах программы» и задаёт лимит.
- Если сеть или кошелёк это не поддерживают, автоматически используем текущую схему (спонсорство или ETH).
- В интерфейсе показываем «Комиссия: N баллов» вместо ETH.

## Этап 2 — Условные транзакции для автоматизаций и ваучеров
- Ваучеры с датой окончания проверяются прямо в сети: после истечения программы погашение отклоняется самим блокчейном, а не только нашим сервером.
- Автоматизации (приветственные сертификаты, офферы «Мы скучаем») подготавливают транзакции с окном действия, чтобы устаревшие не исполнялись.

## Этап 3 — Агенты и документация
- Эндпоинт подготовки транзакций для агентов получает параметр «оплата газа в токене».
- Обновляем llms.txt, OpenAPI, skills и Bazaar-описание: Cobalt, газ в B20, условные транзакции.
- Цены и тарифы не меняем.

## Проверка
- Base Sepolia: деплой программы, выпуск, перевод с газом в баллах, погашение ваучера, отказ по истёкшей программе.
- Mainnet: один тестовый прогон на админ-кошельке после активации.
- Существующие тесты (Deno и E2E) должны остаться зелёными.

## Технические детали
- Новый модуль `src/lib/cobalt/` (детект активации по chainId + номеру блока/времени, энкодинг gas-token полей транзакции) и `_shared/cobalt.ts` для Edge Functions.
- Точные форматы полей транзакции берём из спецификации docs.base.org/base-chain/specs/upgrades/cobalt; до их подтверждения на Sepolia функции спрятаны за feature flag `COBALT_GAS_TOKEN_ENABLED`.
- Изменения: `useDeployB20Token`, `useTransferTokens`, flow погашения ваучеров, `agent-prepare` (новый query-параметр `gas_token`), `_shared/program-validity.ts` (onchain validity window).
- Builder code `bc_wdmnog7m` сохраняется во всех новых транзакциях.
- Windows maintenance-баннер управляется датами в конфиге, без деплоя функций.
