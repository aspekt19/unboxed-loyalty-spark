# Настройка автоматической проверки экспирации программ

## Обзор

Система автоматически проверяет даты экспирации программ лояльности и обрабатывает их:

1. **Программы, истекающие в течение 24 часов** - помечаются статусом `expiring_soon`
2. **Истекшие программы** - помечаются статусом `expired`, их награды деактивируются, а активные ваучеры закрываются
3. **Программы НЕ удаляются** из базы данных и могут быть реактивированы мерчантом

## Настройка Cron Job

Чтобы автоматически проверять экспирацию программ, настройте cron job в Supabase:

### 1. Включите расширения pg_cron и pg_net

Выполните в SQL редакторе Supabase:

```sql
-- Включаем расширения
CREATE EXTENSION IF NOT EXISTS pg_cron WITH SCHEMA cron;
CREATE EXTENSION IF NOT EXISTS pg_net WITH SCHEMA net;
```

### 2. Создайте cron job для проверки каждый час

```sql
-- Проверяем экспирацию каждый час
SELECT cron.schedule(
  'check-program-expiration-hourly',
  '0 * * * *', -- Каждый час в начале часа
  $$
  SELECT
    net.http_post(
        url:='https://YOUR_PROJECT_REF.supabase.co/functions/v1/check-program-expiration',
        headers:='{"Content-Type": "application/json", "Authorization": "Bearer YOUR_ANON_KEY"}'::jsonb,
        body:='{}'::jsonb
    ) as request_id;
  $$
);
```

**ВАЖНО:** Замените:
- `YOUR_PROJECT_REF` - на ID вашего Supabase проекта
- `YOUR_ANON_KEY` - на ваш anon ключ

### 3. Проверьте созданные задачи

```sql
-- Посмотреть все cron задачи
SELECT * FROM cron.job;

-- Посмотреть историю выполнения
SELECT * FROM cron.job_run_details ORDER BY start_time DESC LIMIT 10;
```

### 4. Удаление cron job (если нужно)

```sql
-- Найти ID задачи
SELECT jobid, jobname, schedule FROM cron.job;

-- Удалить задачу по ID
SELECT cron.unschedule(YOUR_JOB_ID);
```

## Логика обработки

### При истечении программы:

1. **Статус программы** - меняется на `expired` в базе данных
2. **Награды** - все награды программы деактивируются (`is_active = false`)
3. **Ваучеры** - все активные ваучеры помечаются как `expired`
4. **Программа** - ОСТАЕТСЯ в базе данных и может быть реактивирована мерчантом

### Реактивация программы:

Мерчант может вручную реактивировать expired программу через UI:
1. Нажать кнопку "Activate" в списке программ
2. Это вызовет `unpauseUtility` в смарт-контракте
3. Статус в БД изменится на `active`
4. Ваучеры могут быть реактивированы

## Примечания

- **Автоматическая пауза контракта невозможна** - требует транзакции от владельца
- **Edge function запускается вручную или по cron** - не может напрямую взаимодействовать с блокчейном
- **Программы сохраняются** - не удаляются, доступны для повторной активации
- **Награды и ваучеры** - деактивируются автоматически, защищая от использования истекших программ
