## Слайд 6: Продукт

**Два портала + один программируемый API**

### Сценарий бизнеса
1. **Запуск программы** — Создайте ERC-20 токен лояльности на Base за минуты
2. **Работа с лояльностью** — Начисление по email/телефону/кошельку, ваучеры, уровни, RFM, автоматизация
3. **Приглашение команды и агентов** — Филиалы, сотрудники, AI-агенты со scoped API-ключами

### Сценарий клиента
1. **Получение токенов** — Токены лояльности приходят в смарт-кошелёк (Privy / SIWE)
2. **Погашение и обмен** — Трата на награды или обмен P2P через onchain-эскроу
3. **Реальное владение** — Токены хранятся в кошельке клиента, полностью переносимы
