01 · Problem

Loyalty is stuck in the last century

Traditional programs are expensive for businesses, worthless for customers, and closed to automation.

💸

Expensive for merchants

Legacy SaaS charges $99–499/mo or takes 15–30% of program revenue.

🔒

Customers don't own points

Points live in someone else's database — they can be devalued, expired, or revoked with no recourse.

🤖

Closed to agents

Programs are siloed with no API for AI agents and machine payments — the fastest-growing commerce channel.

02 · Solution

Dual-mode loyalty platform

One protocol, two interfaces: humans use the portal; AI agents use API and MCP. Shared contracts, tokens, and database.

🪙

Own your program

Deploy your B20 loyalty token on Base (default). Mint, transfer, and redeem onchain.

💵

Pay per use

Predictable USDC SaaS plans. No revenue cut. No hidden lock-in.

⚙️

Automate with agents

AI agents run programs via REST + MCP, paying per call with x402 / MPP micropayments.
