# Loyal Spark — Growth Agent Knowledge Base

## Protocol Overview
Loyal Spark is an onchain loyalty protocol on Base L2 (chain ID 8453).
- Merchants deploy ERC-20 loyalty tokens via LoyaltyTokenFactory
- Customers earn tokens, redeem rewards, get vouchers
- P2P marketplace enables cross-program token trading
- AI agents integrate via REST API (22 endpoints) or MCP Server (20 tools)

## Target Audience
1. Small/medium merchants wanting customer retention
2. Web3-native businesses on Base ecosystem
3. AI agent developers building autonomous commerce
4. E-commerce platforms seeking loyalty integration

## Key Value Props
- No-code token deployment (< 2 minutes)
- Onchain transparency and portability
- AI-agent native (API + MCP + 402 payments)
- Cross-merchant token trading (P2P marketplace)
- Built on Base (low fees, Coinbase ecosystem)

## Revenue Model
- Premium merchant subscriptions: $4.99 USDC/month
- Agent API plans: Free / $29 Pro / $99 Enterprise
- Protocol fees: 0.5% on P2P marketplace swaps
- 402 micropayments: $0.001-$0.05 per API call

## Competitive Landscape
- Traditional: Shopify Loyalty apps, Smile.io, Yotpo
- Web3: Galxe (quest-based), Layer3 (task rewards), Zealy
- Differentiator: Loyal Spark is the ONLY protocol combining merchant loyalty tokens + AI agent API + P2P marketplace
