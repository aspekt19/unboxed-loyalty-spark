## 🎨 Brand Colors

### Primary Palette
- **Black**: `#000000` - Primary brand color, used for logo and key elements
- **White**: `#FFFFFF` - Background and contrast
- **Foreground**: HSL values from design system - Main text and UI elements
- **Muted Foreground**: HSL values from design system - Secondary text

### Semantic Colors
All colors are defined using HSL in the design system (`src/index.css` and `tailwind.config.ts`)

## 📏 Logo Usage Guidelines

### Spacing
- Maintain clear space around logo equal to the height of the sparkle icon
- Never place logo too close to other design elements

### Colors
- Primary: White sparkle on black square background
- Alternative: Black sparkle on white background (ensure sufficient contrast)
- Never use other colors for the logo

### Don'ts
- Don't stretch or distort the logo
- Don't rotate the logo
- Don't add effects (shadows, glows, etc.)
- Don't change the sparkle icon
- Don't alter the proportions
