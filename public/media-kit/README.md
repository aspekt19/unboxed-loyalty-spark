# Loyal Spark Media Kit

## About Loyal Spark

Loyal Spark is a decentralized loyalty rewards platform built on the BASE blockchain network. It enables merchants to create custom loyalty programs and customers to manage, transfer, and trade their loyalty tokens across different merchants.

## Key Features

1. **Decentralized Loyalty Programs** - Merchants can create custom named loyalty tokens
2. **Token Management** - Customers can view, transfer, and manage tokens from multiple merchants
3. **DEX Integration** - Built-in access to decentralized exchanges for token trading
4. **Blockchain-Based** - Powered by BASE Network for security and transparency
