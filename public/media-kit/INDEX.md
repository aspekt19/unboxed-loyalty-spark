## 📋 Key Information At A Glance

### Brand Name
**Loyal Spark**

### Primary Tagline
"Discover loyalty rewards reimagined."

### Technology
- Built on BASE Network (Ethereum L2)
- ERC-20 token standard
- React + TypeScript frontend
- RainbowKit wallet integration

### Target Audience
- **Primary**: Merchants (small to medium businesses, e-commerce)
- **Secondary**: Customers (crypto-savvy consumers, Web3 enthusiasts)

### Core Value Propositions
1. **True Ownership** - Customers own their rewards as ERC-20 tokens
2. **Tradeable** - Exchange on any decentralized exchange
3. **Transparent** - All transactions on-chain
4. **Cost-Effective** - Low gas fees on BASE Network

### Brand Colors
- **Primary**: Black (#000000) and White (#FFFFFF)
- **Semantic**: Defined via HSL in design system

### Key Features

**For Merchants:**
- Deploy custom loyalty tokens
- Mint and distribute rewards
- Track transactions on-chain
- Build customer engagement

**For Customers:**
- View token balances
- Redeem rewards
- Transfer tokens
- Trade on DEXes
