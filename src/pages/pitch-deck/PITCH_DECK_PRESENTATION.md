## Slide 8: Hub-and-Spoke Liquidity Model

### LOYAL as universal intermediary

```
All merchant loyalty tokens (M-tokens) pair with LOYAL, 
creating a unified liquidity hub.

Any M-token can be exchanged for any other via LOYAL bridge.
```

**Mechanism:** M-Token A → LOYAL → M-Token B (atomic swap)

**Benefits:**
- Universal liquidity across all merchant programs
- No need for direct M-token pairs
- Lower slippage, better price discovery
- Simplified merchant onboarding
